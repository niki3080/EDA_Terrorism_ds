# Terrorism Data Analysis

Exploratory analysis of the Global Terrorism Database.


## Structure

report_EDA – html file with the EDA
notebooks/ – data preparation notebook, EDA Notebook
src/ – helper plotting functions  
styles/ – matplotlib style sheets  
data/ – processed dataset; codebook summary

## Raw data

Download:
https://www.kaggle.com/datasets/START-UMD/gtd

After downloading place the file here:
data/globalterrorismdb_0718dist.csv

Dataset is not included in the repository due to size.
Place the dataset in the /data folder before running the notebooks.
